# 音效与道具取材

自主完成取材，不把候选选择或 A/B 试听交给用户。先复用实际合适的库存，再寻找现成素材；程序合成音效和生图按需要补充。新角色交给 vyibc-character-design，背景音乐与最终混音交给 studio-music，媒体处理复用 media-use，不另建平行素材库。

## 从镜头到素材

读取本集分镜及角色品牌参考，列出实际缺失的道具和声音：动作、材质、接触时间、尺度、透视、手持/桌面/背景用途。比如拆快递可分别需要封闭纸箱、打开状态、胶带与撕胶带/纸板摩擦声；按镜头所需获取，不固定所有拆箱都必须有相同素材套装。

查询真实资产 MCP 的 tools/list，按素材类型、角色、动作/材质标签搜索并翻页，检查具体版本和使用反馈。没有连接时使用本地清单，注明未入共享库。

## 搜索和获取

按 [来源与获取](references/sources.md) 选择入口。利用当前可用网页搜索、浏览器或已安装的来源工具，核对实际参数；名单中的网站不等于已连接 MCP。保存来源页和实际下载来源。搜索可组合具体动作/材质的中英文关键词，不只搜“搞笑音效”或“卡通素材”。

音效先考虑可用的录音/素材库：检查是否混有音乐人声、截断、爆音、过强混响或压缩失真。预览与原件分开记录，不能默默以试听压缩版代替原件。下载后用 ffprobe 检查真实格式、时长、声道和采样率，内部听审关键片段；不能听音就如实保留未听审状态。

道具优先可修改的 SVG 或透明背景素材。图标适合简洁符号和远景；近景、手持、打开/关闭等表演道具需要匹配视角、状态与接触关系，不能直接放大通用图标代替。下载 SVG 后先检查外部引用、脚本和字体依赖再渲染；原始文件保留，清理和改色形成派生版本。

获取文件使用现有下载/浏览器能力，写当前作品目录；校验 HTTP 响应和文件类型，防止把登录页保存成音频/图片。大文件设置大小与超时边界，保留来源、hash和失败原因。来源不可用时改查其他来源，不宣称成功下载。

## 风格融合

以本片真实品牌图和画面为准，调整道具的线条粗细、色板、阴影、质感和同框比例。下班小人/红衣的手绘场景不能随意混入高光写实3D图标。先在实际画面查看轮廓、透明边缘与手物接触关系；用现成SVG能解决时直接编辑矢量，需生成新外观时使用图像工具并实际传入品牌参考。

音效按实际动作点剪辑，保留需要的起音和尾音；材质、力度、距离与画面一致。整片音量和音乐关系交 studio-music，不用同一个提示音覆盖所有动作，不为丰富而堆叠声音。

## 记录和交付

按 ../cartoon-video-studio/references/asset-management.md 使用统一资产服务，支持时 asset_register / asset_revise 登记，不假设 D1 已存在。每项保存：类型、作者、发现页、原文件来源、代码/素材各自许可、使用与归档范围、hash、派生关系、角色/动作/材质标签、实际检查范围、项目使用区间。未知许可只保存来源卡。

用户不希望公开文案写来源时，选允许这种用法的素材，不能通过删署名或只放私有台账代替许可要求。库文件免费、工具开源和素材可商用是不同判断。

交付本片实际使用的素材与清单，不强制候选页。有真实可用文件才算获取完成；有画面/听音检查才记录对应质量结论。素材库不可用时保留本地清单并注明待入库。
