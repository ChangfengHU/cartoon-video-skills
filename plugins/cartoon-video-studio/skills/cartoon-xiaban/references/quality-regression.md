# 同品牌新作品：防止表现力退化

这个检查针对下班小人的喜剧动画，不是所有视频必须套用的镜头模板。已有失败：纸色、三根头发和技术参数都正确，前半段却变成两种姿态配购物卡片，人物也比认可片更幼、更圆。它只能证明流程能跑，不能证明品牌质量已稳定。

## 用认可作品校准，而不是重新设计“可爱小人”

用户给了认可成片时，先查看其普通状态、疲惫、得意和惊讶的实际帧，并抽看几段连续动作。包内 `assets/calibration/approved-95s-encoded-contact.jpg` 是已认可95秒片的实际帧，不含私人音频；它只校准表现，不拿来替新片讲旧故事。身份图约束辨识点，认可片约束表演与画面层级；不要仅凭六格漫画中的夸张表情重建所有常态脸。

比较头身比例、下颌与脸宽、常态眼睛大小、腿长、线条和排线。可爱不等于再放大头眼、缩短腿或默认微笑。新图与参考并列展示；常态、疲惫、惊讶应是同一个人，不是三个相似角色。新姿态需要参考，但已认可姿态仍可合理复用；生成了新图不是质量加分项。

## 在生图前解决“上面卡片、下面小人”

先为每个事件写出身体或空间发生的变化，以及为什么需要这个景别。屏幕、数字和文字可以成为证据，但角色不应长时间只做证据下方的点按动作。

若连续镜头只有卡片文字变化，同一姿态、同一机位、同一舞台不变，先合并或重写分镜；不要用换标题、额外音效、轻微摆动或持续缩放补救。故意重复用于回扣时，观众应能看到新的反应或代价。近景要让人读到表情，远景要让动作与道具关系发生变化，而不是只把同一幅画放大缩小。

绘制一个片头到中段的缩略分镜带，隐藏文字检查：是否仍看得出事件在升级？若必须读每张卡才能知道剧情，只剩解说而没有足够的角色小剧场。修改故事行动或换更适合动画的表现方法后再生成素材。并非一律禁用手机或卡片，也不强制每隔几秒切镜。

逐句音频是时间素材，不是“一句一个同版式画面”的镜头模板。一场可以跨数句完成连续动作，也可以一句内切到反应特写。常驻页眉把每句再解释一遍、人物一直全身居中，会挤掉表演空间；只有提示本身是剧情事件时才出现提示。将新片和认可帧都缩到手机尺寸，对照是否仍能读到眼神、眉毛和手上动作；缩小角色给文字让位不是改善构图。

## 先验证一个动作，再扩成整片

生图额度有限时，第一批保留给故事中最关键的前后姿态、接触道具与画风测试，不一开始耗尽额度。用这些资产先渲染一个短小的实际动作片段（通常4–8秒即可）：观众看得到刺激、角色主动动作、接触或避让、表情后的反应。它是当前新工程中的创作自检，不引入旧工程；用户已授权直接成片时不额外等审批。

看样片而不是只看分镜文字：接物是否只是一件东西悬在始终张开的手前？开门是否门自己打开而人物不看不碰？可用匹配的前后姿态或分层完成接触，也可改变镜头把不必要的复杂关节动作移到画外，再用清楚的结果和反应兑现。不能把静态手势加平移当作已经完成表演。

同时将角色与本片道具放在同一帧看线条、填色和遮挡。新画道具若只有规则的细线和几何轮廓，而人物有粗细变化、排线与实体感，应补同风格素材或调整笔触；代码只是实现方式，不应凭空带来另一套画风。处理不透明图集纸底时对照处理前后脸、衬衫和浅排线，不能为去矩形边界把人物内部也变透明，让窗线和背景穿进身体。窗口等背景线不必每镜固定保留。

短样片明显退步时先修复该原因，再扩整片。发现整片仍有同类问题，也应在当前冻结skill允许的创作自检内修复；QA诚实记录不等于缺陷自动豁免。遵守本次素材与运行预算，预算内解决不了则交付标明未通过的候选和具体原因，不伪造通过、不无限追加付费调用。

## 素材为动作服务

按故事设计常态、盘算、受挫、掩饰、失控、发现、收尾等真正需要的状态，不机械凑数量。先核对每个关键动作所需的视线、手势、接触点和前后姿态，再开始排整片；缺动作就补对应素材或重排事件，不让一张“点手机”图代演全部情绪。

保留期待→事件→反应→决定的顺序。包袱前的停顿要有角色在等待、憋住或想明白的状态；中性图停很久不自动成为喜剧留白。末镜应表达这次事件之后的态度，不能只复用早先的惊讶图并盖一句结论。

## 成片逐项对照，不用总分掩盖短板

记录比较范围与证据时间点，分别给出“保持 / 下降 / 待验证”，不要伪造客观艺术评分：

| 维度 | 要看什么 |
| --- | --- |
| 角色身份与画风 | 比例、常态表情、线条是否漂移，而不只是颜色相同 |
| 分镜与构图 | 角色是否主导画面；文字卡、重复舞台是否挤掉可见行动 |
| 动作表演 | 刺激、视线、预备、接触、反应是否清楚；重复是否有新含义 |
| 故事与节奏 | 开头是否立即发生事情，升级是否改变局面，结尾是否由行动兑现 |
| 声音 | 台词可懂度、表演、音效接触、音乐留白和尾音；未听则待验证 |

对最终编码的 MP4 做逐场景抽帧，并看开头、中段动作、包袱和结尾的连续片段；HTML截图不能替代实际成片。完整主观听审、ASR、响度检查分别记录，不相互冒充。若工具不能听音，可以交付待听审候选，不能写“声音质量通过”或“整体不降级”。

明显短板先记录为本轮未通过。用户要求先看结果时可交候选，但不能晋升默认资产、宣称质量稳定，或用“制作100%”掩盖验收未通过。

## 当用户要求验证 skill 的可复用性

把可泛化的修正留在 skill，原始失败证据留在私有评测目录。每次修改 skill 后，用全新会话、新作品目录和冻结的 skill 版本再次执行同样的真实任务；不能 resume 旧会话继续改片来证明新 skill 有效。

新会话只获得正常用户需求、必要的授权运行资源、品牌包和认可的原始参考；不额外提供控制者的改片答案、失败诊断、旧工程或聊天历史。创作 Agent 不修改安装包，以免产生未登记的测试变量。

保存 skill 摘要哈希、任务提示哈希、会话 ID、原始 MP4、评测与验证边界。清理限于已登记且已停止的本任务会话；保留作品及脱敏评测，绝不批量清空用户的会话目录。复用已验证的浏览器/字体/TTS运行适配不等于复用旧创作答案。
