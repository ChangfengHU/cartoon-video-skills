# 可移植运行环境

本包不保存个人目录、服务器IP、凭据、真人参考声音、模型权重、第三方音乐或字体。安装skill不等于安装所有依赖；不得为补齐环境自动下载大模型或开启付费服务。

已验证实现：HyperFrames CLI 0.8.30，Node.js 22+、本机Chrome和FFmpeg。依当前引擎skill核对版本，不把固定版本当作永远最新。IndexTTS 2.5 MLX 8-bit是已用过的本地适配，不是官方原生后端或唯一选项；读取实际manifest并记录模型修订。

品牌规则不区分 ARM/AMD，但二进制依赖必须检测 OS、CPU 架构和加速器。不要在 Linux 上安装 Apple MLX 权重并当成通用后端，也不要为了做一部视频强制在无 GPU 的服务器安装大模型。按 [voice-routing.md](voice-routing.md) 优先使用项目已授权且能短测成功的配音服务；音频可以在另一台机器生成，再经私有 R2 或 SSH 传到渲染机。渲染端只依赖已冻结的音频文件和时间轴。

参考声音必须获授权；已有缓存先核对身份与模型版本。每句缓存键包含文字、参考哈希、模型修订、情绪设置及种子。CAMPPlus初始化失败不得继续用随机权重；需要时严格加载环境已有checkpoint，失败就停止该生成路径。

本包保留配置方法，不携带使用者的音色库。通过显式项目路径和私密配置提供运行资源。读acting-recipe.md：prepare_demo.py接收已获准的音频、时间轴、中文字体与GSAP文件；可选提供已安装media-use音效目录。不在别人私有目录里猜测依赖。

build-demo.mjs只构建“先写两行”这个示例。新主题复用表演方法、重新设计事件；不能只换字幕称为新故事。
