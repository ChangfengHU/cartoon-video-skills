# 配乐与音效

默认由制作 agent 自主找曲、选曲并用于成片，不要求用户选择候选，不强制制作 A/B 试听页或等待音乐审批。用户明确要求比较时再提供试听方案。自主决策不等于省略内部听审：元数据、自动排序和渲染通过都不能证明好听。

读取 ../cartoon-video-studio/references/asset-management.md；研究抖音线索时读 ../cartoon-xiaban/references/music-research.md。按剧情确定音乐的情绪、密度、对白空间、转折和收尾，写入 MUSIC_PLAN.json。曲目数量和候选数量由故事需要决定，不固定每片同一首或每镜换曲。

## 获取与选择

BGM、环境声与动作音效先读[共用音频 MCP](references/audio-mcp.md)，调用 `auto-parse-audio` 的能力检查和已验收库检索。库中不合适再搜索授权来源；特殊需求才询价并取得费用确认后生成。自主选曲不代表可自动付费或替用户确认候选批准。已认可的项目冻结文件和原资产库仍可复用，不迁移、不改旧 ID。该 MCP 不替代配音或 HyperFrames 混音。

用户需要热门风格或素材库不足时，使用实际可用的抖音搜索、音乐榜单或同类作品解析能力，研究配乐怎样服务开场、动作、笑点和反转。发现工具时核对真实 tools/list 和参数；有榜单才称榜单，有相关作品只能称同类作品样本。记录查询词、日期、作品链接及实际返回的 music ID/标题/作者，不用个人观看记录代替平台搜索，不凭熟悉程度称一首歌“当前热门”。研究线索不等于取得音乐许可。

热门是候选发现方向，最终以剧情匹配、音乐本身质感、对白清晰度、可剪辑性和使用范围决定。适合本片的其他曲目可以胜过热歌。当前用户喜欢已有下班小人和红衣女生的配乐效果：对应角色沿用已认可成片的氛围、音乐密度及笑点衔接作为参考，不把某首歌曲绑定角色，不把喜剧配乐套到所有新风格，也不把整体满意当作逐曲授权或试听结论。

查询资产 MCP 的库存和实际反馈；对相关结果翻页，比较合适旧素材与新发现。抖音线索不足、原曲不适合或连接不可用时，继续从作者原曲渠道和音乐/音效库取材，记录原因，不静默声称已查抖音。Mixkit、Incompetech、Pixabay、Freesound 是可调查来源，不是已全部接通的自动工具，也不是限定名单；实际访问方式、账号条件和许可须按来源核实。区分可搜索、可试听、可下载原件和可归档；不能用有预览链接来证明已取得原件。媒体获取按 ../media-use/SKILL.md。

内部听审重点是选中片段与实际对白/画面的关系，以及音频是否有残留人声、失真、明显压缩或不合适的尾音。无需穷举曲库或交付候选表；找到充分适合的音乐即可作出决定，留简短选择理由。无法实际听音时标明仅元数据筛选及未听审，不宣称质量已验证。

## 音效与混音

音效获取使用 [素材取材](../studio-materials/SKILL.md)，优先查合适的现成声音。音效按可见动作、材质、接触帧、力度和空间感选择；分别考虑环境底声、动作声、转场及喜剧强调。优先合适的真实素材，程序合成按表达需要补充，不默认每个动作使用同一提示音，不以音效数量衡量丰富程度。

混音按 ../hyperframes-audio/SKILL.md。对白优先，音乐避让；段落自然衔接，尾句后留收束。真实响度和听审决定增益，不统一套音量百分比。检查实际完整音乐轨及最终成片的循环接缝、意外断乐、音量突变、刺耳音效、对白遮盖和尾音截断。刻意停乐可服务笑点，要与意外缺轨区分。

../cartoon-xiaban/scripts/plan_music.py 可按其输入格式辅助排序已核验本地素材，但不负责搜索、授权判断或听音，也不是必经步骤。

## 来源与复用

从 `auto-parse-audio` 取得的文件保留服务 assetId、hash、许可、标签和原任务 ID；候选人工验收后再 approved，实际采用才 `audio_use_asset` 记录本片用途。更新标签先读取保留原字段。私有文件经鉴权下载核验后交本地渲染，禁止公开 Token 或把私有媒体链接写进 HTML。原 `asset_register/asset_revise` 仍用于原库，不把新服务 ID 当作旧库 ID，也不声称旧库数据已自动迁移。

记录发现来源、作者原曲来源、使用片段、情绪/用途、对白兼容性、文件 hash、许可平台及署名/归档范围；BPM等区分目录值、估计和实测。抖音视频混合音轨不是纯 BGM，热门不等于可下载重用。许可未知只保存来源卡。用户要求发布文案无曲名时选择无需公开署名或已获对应许可的音乐，不能删掉必要署名来满足要求。

使用实际可用的 asset_register / asset_revise 等资产工具入库、追加标签和使用反馈；冻结本片版本，不覆盖旧片引用。没有资产服务时保留项目内清单并注明尚未入库。交付以成片为主，MUSIC_PLAN、音效时间点、来源/许可、检查范围和未验证项存随片记录，不把选曲过程变成用户的必做任务。
