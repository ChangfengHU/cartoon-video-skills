# 成片质量与返修

有锁定台词的配音必须执行 [配音完整性与返修](references/speech-integrity.md)：源配音与最终MP4各自做ASR差异检查，证据绑定当前文件哈希。漏词、错词或待解释差异不能靠技术通过抵消；使用 scripts/speech_check.py 执行内容检查。ASR一致仍不等于听审通过。

从实际MP4取证，不只看HTML预览。使用 ../hyperframes/SKILL.md 路由CLI检查，按 ../cartoon-xiaban/references/quality-regression.md 对照用户指定参考片；新角色比较清晰度、表演和节奏，不要求长相相同。

交付QA分开列：技术检查、视觉检查、听审、用户反馈。记录文件哈希、检查片段、连续帧采样时刻和证据路径。没检查填 pending；发现问题填 fail 和对应时间。用户认可只能引用真实原话，不由自动流程生成。

技术：ffprobe实测尺寸、帧率、时长、编码与音轨；确认文件可解码。视觉：开场、每个场景、所有转场、最后一镜；检查身份/道具漂移、字幕裁切、文字错误和手部。至少对关键动作采样预备/接触/反馈连续帧。听审：开头、转折、混音变化和结尾；要声称全片听审必须实际听完整片。

按视频类型复核观看理由与推进：角色短剧可看冲突升级，热点追踪看关键现场是否充分展示、解说是否帮助理解画面、结尾是否承接实际发现；不强套冲突、批判或每三秒切镜。

质量记录格式：{"checks":[{"dimension":"visual","status":"pass|fail|pending","evidence":"相对文件路径或观察记录","range":[0,3],"finding":"具体发现"}]}。技术通过与视觉/听审通过分别保留；不凭完整字段宣布质量通过。

返修先定位源任务：配音问题修对应voice任务，接触动作修scene任务，背景音乐缺段修mix任务。production_state.py invalidate 标记下游过期，保留旧输出与历史，生成新版本再比较。结果不明的云任务先恢复原job_id，不重复付费提交。

可用 ../cartoon-video-studio/scripts/qa_summary.py QA.json 汇总检查状态；它只验证已填记录，缺维度保持pending，不产生用户批准或客观质量分。

资料型视频还需按 [编辑衔接](../cartoon-video-studio/references/editorial.md) 对照 EDITORIAL.json 检查最终MP4：是否遗漏入选发现、是否需要的解释缺失或解说反而遮住了值得观看的过程、证据与台词是否匹配、开头承诺是否兑现。观察绑定最终文件哈希；重渲染后旧检查不能沿用为通过。editorial_check.py仅校验记录，不自动证明质量。

渲染前的视觉抽样应覆盖实际使用的不同版式和叠层组合，不仅取固定数量的等距缩略图。标签、说明、字幕在独立轨时，要放大检查交叠区；自动layout零错误仍可能遗漏跨层遮挡。返修后重查涉及的版式，并在最终MP4确认。

编辑复核还要检查信息增量：主张是否只在复述基础能力，比较是否有基线，重复段落是否仍在凑时长。视觉复核单独判断风格连贯与画面解释效率；字段齐全、字幕可读不能作为内容有价值或可发布的依据。若问题出在论点，返回编导任务，不能只修字体和动画。

连续素材的抽样边界包含源镜头入点/出点及镜头内部切换，不只按旁白段落或页面边界。入点前后短暂混入无关画面、视频与底下静帧同时可见，均应检查实际导出的像素。对比度也需覆盖真正显示后的浅色场景辅助文字，不能仅凭稀疏自动采样推断全片通过。

热点追踪和已有版本返修时，读取 editorial.md 对应分支，逐项对照BRIEF的基线与保留项。完整看听新旧版本后再判断节奏是否改善；若只检查局部，写明局部范围，其余pending。具体记录原片动作是否被剪断、动态现场是否被长时间静图取代、解说是否强加了素材不能支持的立场。素材数量、动态占比和字段齐全都不能自动证明更好看；不把批评多当作观点强。

按 [制作与验收证据](../cartoon-video-studio/references/release-evidence.md) 核对当前文件哈希、参考版本、逐维度范围及方法，并运行工作室 release_check.py。ASR 不能作为表演听审；旧文件验收不能复用于新文件；模型评价与实测矛盾时不采纳其通过结论。

连续采样生成联系表时，先在滤镜链中trim到声明范围，再fps和tile；仅用输出参数-t可能让tile先读入范围外帧。记录原片时间、fps和实际查看的文件；末尾补格不算原片黑帧。
