# 0.5.0 角色制作工作流

新增studio-character-workflow：参考图溯源、角色数据档案、用户策略选声、可选示例片、认可范围与验收、私有参考预览与浏览器读回。复用已有生产账本、质检器与资产服务，不新增调度系统。插件包含20个skill、8个MCP声明；新增behavior、xiaohongshu、vault只是连接声明，需分别配置VYIBC_BEHAVIOR_TOKEN、VYIBC_XIAOHONGSHU_TOKEN、VYIBC_VAULT_TOKEN，不携带账号或全库凭据。用户不需要这些来源时不调用。

现有角色skill兼容；普通新增人物按私有库数据扩充，不要求每人新增skill。用户禁用声线保存在租户/项目策略，公共包无私人声线绑定。阿里云预置、已有授权Cosy与豆包按真实后端能力选用，不将Qwen ID传给豆包MCP。

私有参考归档不是公开传播授权。服务增加窄许可状态，禁止进入publication freeze。UI同源鉴权展示参考图，未授权读图应拒绝。

质量状态与技术证据分开；已有作品认可不证明新项目也稳定。历史工程补录的生成输入回执不冒充当时保存。本次未启动Pi/定时器，未改全局安装技能。完整实测/部署版本以发布记录为准。
