# 故事编导

接收用户思路或外部资料包；选题研究是独立可选能力，不要求每次制作先上网。出现缺失的事实时保留缺口或回交独立研究，不能把剧情补写伪装成事实。

资料型解读先按 [编辑衔接](../cartoon-video-studio/references/editorial.md) 从资料形成发现与取舍，再写脚本。每个入选发现对应观众收获、声画和证据角色；没有采用的发现保留理由，不要求全部入片。切勿从某次返修硬编码具体卖点、人物、配乐或固定章节。

先写 BRIEF.md：目标观众、核心冲突、时长/画幅/帧率、角色偏好、用户约束、来源包位置。沿用已有授权，不要求中间审批。默认沿用用户给定时长；没有指定时以工作室约90秒竖屏为起点并明确假设。

写 SCRIPT.md，开头直接展示冲突或后果，中段用行动升级而不是重复解释，结尾解决或回扣开头，留出反应和音乐收束。角色台词应能说出口，不把所有事实塞入旁白。区分旁白、对话、镜头内文字和动作，不靠大段字幕替代剧情。

选角读取工作室 characters.json 和人物档案；按本集身份/情绪/喜剧机制给出匹配理由及缺失资产。已有人物能演新场景时复用，不因为换选题就新建人物。需要新人物时调用 ../vyibc-character-design/SKILL.md；本集动机与固定人设分开。

新角色的候选/视觉检查/用户认可分别记录。用户授权直接制作时，可明确以已视觉检查的候选制作样片或本集，不把 --approved 校验门槛当成必须等待中间审批；不得伪造批准。纳入长期默认需真实反馈。

先生成真实配音再定精确时序，逐镜记录人物意图、表情、视线、动作预备/接触/反馈、对白区间和音乐功能。SCRIPT、STORYBOARD、MUSIC_PLAN与素材锁一起交给 HyperFrames。新角色最小动作样片优先复核同一身份与动作接触，再扩展全片。

任务用工作室 scripts/production_state.py 保存依赖和实际输出；镜头级任务如 voice-03、scene-03、mix、render、qa。只改一句台词时使相关镜头及下游失效，其他已验证资源复用。
