# 下班小人 11 节点全链路制作工坊

涵盖下班小人从选题策划到最终 R2 CDN 交付的完整 11 个独立节点执行流水线：
- node-01-topic: 爆款选题策划（Qwen 动态生成 + 痛点大纲）
- node-02-script: 幽默编剧工坊（12幕三幕反转结构与四层条漫元数据）
- node-03-storyboard: 分镜导演台（15-Pose防重多样化、条漫印章与音效对齐）
- node-04-director-guard: 导演安全网（台词与镜头数量门禁）
- node-05-visual-assets: 视觉素材中心（角色透明图与条漫组件清单）
- node-06-voice-tts: 声音工厂（CosyVoice v3.5-plus 逐句情感配音）
- node-07-audio-foley: 音效对齐师（毫秒卡点时间轴与戏剧急停标记）
- node-08-media-guard: 媒体安全网（音频哈希与时长一致性校验）
- node-09-animator: 逐帧舞台合成（条漫四层排版引擎 + EBU R128母带混音）
- node-10-qa: 质检审查庭（音画同步、黑帧检测与技术指标验真）
- node-11-delivery: 交付与分发（Cloudflare R2 CDN 上传与凭证生成）
