# 指令帮助

- `/studio`：工作室菜单：选择已有角色或创建新角色。参数：[帮助或制作要求]。
- `/studio-xiabanxiaoren`：下班小人：生活观察、消费与职场喜剧。参数：[主题；留空主动研究选题]。
- `/studio-hongyi`：红衣女生：女性独白、生活喜剧与反转故事。参数：[主题；留空主动研究选题]。
- `/studio-ali`：阿栗：都市生活、机灵吐槽与自嘲喜剧。参数：[主题；留空主动研究选题]。
- `/studio-new`：新角色：真实参考、设计、选声并制作视频。参数：[抖音喜欢/小红书/参考图/主题；可只设计角色]。
- `/studio-help`：查看指令与角色介绍、预设提示词和使用示例。参数：[指令名]。
- `/studio-revise`：修改已有作品并对照旧版检查。参数：[工程或视频] [修改要求]。
- `/studio-check`：检查实际成片，不默认修改。参数：[视频或工程]。
- `/studio-publish`：准备文案封面并发布指定作品。参数：[作品] [平台/账号]。

Claude项目/Pi使用 /名称；Codex当前支持 $名称，旧CLI/IDE可选 /prompts:名称。菜单是否加载以当前客户端实际状态为准。

例：`/studio-ali` 主动选题制作；`/studio-hongyi 主题：网购凑单`；`/studio-new 从小红书找参考`；`/studio-new 抖音喜欢，只设计角色`。
