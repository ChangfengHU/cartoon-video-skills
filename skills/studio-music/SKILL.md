# 配乐与音效

读取 ../cartoon-video-studio/references/asset-management.md 和 ../cartoon-xiaban/references/music-research.md。先按镜头写 MUSIC_PLAN.json，情绪、能量、对白、刻意停乐与收尾原因逐项对应。不能默认每片使用同一首歌，也不能把连续配乐误解为包袱处禁止停顿。

查资产MCP的真实 tools/list。asset_search 全部翻页后再比较旧曲，主动研究新候选。用户要求参考抖音时，调用独立平台搜索/浏览器与解析能力，保存实际返回的music ID和原曲线索；未连接时记录 unavailable 并研究可用作者曲库，不宣称已查抖音。研究入口属于外部依赖，不在工作室另建全站采集器。

每首记录发现来源和作者原曲来源、候选片段、情绪/用途、BPM及测量或目录依据、人声有无、对白兼容性、许可平台/署名/归档范围。许可未知只保存来源卡。抖音混合音轨不是纯BGM；元数据和规则排序不是试听。先选有差异的候选，同一段画面和人声做短A/B比较，记录实际听过的范围。

沿用 ../cartoon-xiaban/scripts/plan_music.py 做已核验本地候选的场景排序；先读其输入格式。它不负责搜索、授权判断或听音。用户要求发布文案无曲名时，排除仍需公开署名且无替代许可的曲目，不能删掉许可要求。

混音按 ../hyperframes-audio/SKILL.md；媒体获取按 ../media-use/SKILL.md。语音优先、音乐避让、转场交叉淡化、尾句后留收束；真实响度和试听决定音量。音效记录触发动作和接触帧，不用重复提示音代替表演。

对实际完整音乐轨检查循环接缝、源曲尾部静音和最终淡出。曲目时长不足时先选合适接续片段或交叉衔接，不假定直接循环无缝；发现静音需区分刻意留白与断轨。保留修复前后证据，不能只看总时长或全片平均响度。

入库用 asset_register；支持时用 asset_revise 追加标签/停用版本，不覆盖旧记录。登记引用的资产ID并冻结本集。使用反馈只能是实际观察，整片满意不自动给每首曲目 user_approved。交付 MUSIC_PLAN、候选比较、最终时间线、来源/许可和未听审项。
