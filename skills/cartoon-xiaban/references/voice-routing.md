# 配音可替换，不阻塞成片

目标是稳定产出有趣的卡通作品，不是要求每个渲染节点都部署同一模型。用户明确要求本人声线时优先保留身份；用户允许云端或其他音色时，可按可用性切换，并在制作记录中说明。公共 skill 不携带 Token、服务器地址、私人参考或声线样本。

## 路由与停止条件

先检测运行环境、现成配音配置、账户权限和当前项目的声线限制。优先选择已能工作的路径，不在生产任务里重新做模型排行榜：

| 路径 | 适用条件 | 处理方式 |
| --- | --- | --- |
| 豆包或其他已配置云 TTS | 用户已授权调用，声线/服务权限匹配 | 短句验证后生成整片；凭据由私有环境注入 |
| 可用的 Mac mini 配音节点 | 本人声线或指定 MLX 后端仍需使用，节点可连接 | 在该节点生成，音频与非敏感时序清单经私有 R2 或 SSH 交给渲染端 |
| 已安装、实测可用的 Linux TTS | 后端确实支持当前架构，速度和内存合适 | 使用现有模型；新安装/大模型下载单列任务，不作为成片前置条件 |
| Cloudflare Workers AI 等候选 | 其他路径不可用、用户允许替代且账户有额度 | 先核实当前模型、语言、权限和额度并试听；不能把“免费额度”写成无限免费或保证质量 |

用户指定顺序时覆盖本表。每条路径先用约 10–15 秒文字做连通性、解码和时长验证。网络超时/临时服务错误至多重试一次；401/403 检查一次凭据类型、resource ID 与音色权限，不盲目重复请求或声称整个 Token 无效。仍不通就切换已授权路径；全部不可用才报告准确的阻塞项。不要为了修配音连续阻塞整片制作。

Mac 不可用时不创建伪装成本地推理的桥接；Linux CPU 路径未实测不能称为可用。新片中统一同一角色的音色；切换后应重生受影响台词，不在半片中无说明地换声。

## 冻结与跨机器交付

生成端交付完整可解码的 WAV/MP3 和配套 manifest：provider、model/revision、voice_id、是否本人克隆、文本与逐句表演意图、参数、音频 SHA256、采样率、声道、实测时长。超时结果不明确时先查本次缓存/任务状态，避免重复收费。缓存键包含文本、模型、音色、参数；克隆还包含参考哈希。

渲染端下载后校验哈希并探测时长，冻结到作品的本地 assets/audio，再排镜头。不能在最终渲染时依赖将过期的远程音频 URL，也不能换配音后沿用旧时间轴。

R2 是文件传输层，不是配音模型。用任务独立对象前缀、私有桶/短期授权 URL；不因传文件而开放整个桶。默认只传本次生成音频与 manifest，不传真人参考、原视频或模型缓存。用户要求清理时仅处理本任务登记的对象，不删除别人的素材。
